# Brandon Delgado — Personal Website

Portfolio site in the dark manifesto design: an ember horizon, six principles, and a prerendered proof page for each one.

## Live Site

https://brandon-delgado.com

## Tech Stack

- React 19 + TypeScript (strict)
- Vite (build tool & dev server, with prerendered HTML per route)
- Bun (package manager & script runner)
- Tailwind CSS
- Self-hosted fonts, CSS atmosphere (no canvas)

## Running Locally

```bash
bun install
bun run dev
```
